# 위험지수 — 자료, 계산, 등급

출처는 팀 노션 「프론트엔드 기획」의 「데이터 / 분석 기준」 시안(`plan-images/data-criteria-draft.jpg`)과 탐색 화면 시안입니다. 가중치와 등급 경계는 시안의 예시값이며, 시안에도 「가중치는 최종 분석 모델에 따라 조정될 수 있습니다」라고 적혀 있습니다.

## 데이터 기준

- 기준 연도: 2025년
- 분석 대상 지역: 서울특별시 25개 자치구
- 분석 단위: 개별 주차장

## 사용 자료

| 자료 | 내용 | 출처 |
|---|---|---|
| 강수량 | 2025년 기상 관측자료(시간·일별 강수량) | 기상청 |
| 지형·고도 | 지형의 높낮이, 경사도 등 지형적 특성 | 국토지리정보원 |
| 과거 침수 이력 | 과거 침수흔적도와 침수 발생 지역 | 서울특별시 |
| 주차장 | 주차장 위치 등 기본 정보 | 서울특별시 공영주차장 등 |

시안의 주차장 자료에는 시설 유형(지상/지하)이 있지만 쓰지 않습니다. 실제로 쓰는 데이터셋 이름, 받는 곳(링크), 받은 날짜는 자료를 정하면 이 표에 더합니다.

## 분석 과정

1. 데이터 수집 — 공공데이터와 오픈 API
2. 데이터 전처리 — 결측치 처리, 좌표 매칭 등
3. 지표 표준화 — 지표마다 단위가 다르므로 0~1 범위로 맞춤
4. 가중치 적용 — 지표별 중요도 반영
5. 위험지수 산출 — 주차장별 상대적 위험도(0~100)

## 지표별 세부 기준

- 강수량 위험: 2025년 관측 강수량, 최대 1시간 강수량, 최대 3시간 누적 강수량
- 지형(고도) 위험: 주차장 위치의 표고(고도), 주변보다 낮은 땅인지(저지대 여부), 경사도, 하천과의 거리 등
- 침수 이력 위험(시안 이름 「침수사고 위험」): 과거 침수흔적도와의 공간적 거리, 침수구역과의 중첩 여부, 과거 침수 사례 유무

상세 비교 화면에서는 「침수 대표지점까지의 거리」와 「침수구역 중첩 여부」를 따로 보여 주지 않습니다. 계산에 쓰는 것은 막지 않습니다.

팀 확인 필요: 지표 안의 세부 값을 하나로 합치는 방법과 표준화 방법(최솟값·최댓값 기준 등)은 시안에 없습니다.

## 계산식

```text
침수 위험도 지수 = 100 × (α × 강수량 위험 + β × 침수 이력 위험 + γ × 지형(고도) 위험)
```

- 세 위험 값은 0~1 로 표준화한 값이고, α + β + γ = 1 이므로 결과는 0~100 입니다.
- 화면에는 정수 점수(예: 33점)로 보여 줍니다. 반올림은 한 함수에서만 합니다.

| 지표 | 기호 | 가중치(예시) |
|---|---|---|
| 강수량 위험 | α | 0.45 |
| 침수 이력 위험 | β | 0.35 |
| 지형(고도) 위험 | γ | 0.20 |

## 등급

| 등급 | 점수 |
|---|---|
| 상대적 낮음 | 0~39 |
| 보통 | 40~69 |
| 상대적 높음 | 70~100 |

최신 시안(`search-nearby-tab.jpg`) 기준입니다. 예전 시안(`dashboard-draft.jpg`, `search-draft-b.jpg`)은 0~33 / 34~66 / 67~100 을 썼으나 최신 것을 따릅니다. 등급 색은 `product-plan.md` 「색」에 있습니다.

## 안내 문구

시안에 있는 문구입니다. 화면에 넣을 때 그대로 쓰거나 뜻을 바꾸지 않는 선에서 줄입니다.

- 지도·위험지수 옆에 항상: 「2025년 데이터 기반 상대적 위험도 · 실시간 침수 예측 아님」
- 위험지수 설명: 「위험지수는 상대적 위험 수준(0~100)을 의미하며, 실제 침수 발생을 보장하지 않습니다.」
- 분석 결과 해석 시 유의사항(데이터 / 분석 기준 시안)
  - 본 위험지수는 실제 침수 발생 확률이 아닌, 분석 대상 내 상대적 위험 수준을 나타냅니다.
  - 사용한 데이터의 해상도와 시점에 따라 실제 현장 상황과 차이가 있을 수 있습니다.
  - 실시간 강수 상황은 반영하지 않으므로, 집중호우 시에는 기상특보 및 현장 안내를 함께 확인해 주세요.
- 비교 화면 유의사항(상세 비교 시안)
  - 본 서비스는 과거 데이터 기반의 상대적 위험도 비교 결과입니다.
  - 실제 침수는 실시간 강수, 배수 상황, 현장 여건 등에 따라 달라질 수 있습니다.
  - 집중호우 시에는 관할 기관의 기상특보와 현장 안내를 함께 확인해 주세요.

## 앱 입력 자료(제안)

분석 결과는 앱이 읽는 파일 하나로 넘깁니다. 열 이름은 제안이며, 실제 자료가 정해지면 이 표를 먼저 고친 뒤 코드를 맞춥니다.

파일: `data/parking_risk.csv` (UTF-8, 한 줄에 주차장 하나)

| 열 | 뜻 | 값 |
|---|---|---|
| `parking_id` | 주차장 고유 번호 | 문자열, 겹치지 않음 |
| `name` | 주차장 이름 | 문자열 |
| `address` | 주소 | 문자열 |
| `lat` | 위도 | WGS84 십진수 |
| `lon` | 경도 | WGS84 십진수 |
| `rain_risk` | 강수량 위험 | 0~1 |
| `terrain_risk` | 지형(고도) 위험 | 0~1 |
| `flood_history_risk` | 침수 이력 위험 | 0~1 |

- 위험지수와 등급은 앱(`core/risk.py`)이 이 세 값과 가중치로 계산합니다. 가중치를 바꿔도 자료를 다시 만들 필요가 없게 하기 위해서입니다.
- 사용자 위치와 주차장 사이 거리는 위도·경도로 하버사인 공식(구면 위 직선거리)을 써서 계산합니다. 길 찾기 거리가 아닙니다.
- 원본 자료를 이 파일로 만드는 코드는 `analysis/` 에 둡니다.
- 실제 자료가 준비되기 전 화면 개발용 가상 자료를 쓸 때는 이름을 「예시 주차장 NN」처럼 실제와 헷갈리지 않게 하고, 화면에 가상 자료라고 표시합니다.
