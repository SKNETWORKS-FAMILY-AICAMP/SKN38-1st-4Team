# 침수 위험점수

최종 위험지수는 `parking_risk_result_recalculated.csv`의 `total_risk_score`를 주차장 관리번호(`parking_lot_id`)로 연결한 0~100 정수다. 서비스 지역은 강북·강서·도봉·서대문·은평의 주차장 163개이며, CSV 값이 있는 137개는 원점수 그대로 표시하고 나머지 26개는 미산정으로 표시한다. SQL 덤프는 전체 806개를 보관하며 점수가 없는 행은 `NULL`이다.

## 상세 화면의 참고 지표

- 침수심: 원본 침수심 / 전체 침수심 원본의 최대값. 현재 제공 파일의 최대값은 0.5다.
- 저지대: 주차장 관리번호로 연결한 원본 0~100 점수를 100으로 나눈다.
- 강수 원값: 연최대1시간강수량 × 0.4 + 3시간최대강수량 × 0.4 + 집중호우발생일수 × 0.2.
- 3시간 최대강수량: 같은 관측 날짜 안의 연속 3시간 합을 한 시간씩 이동하여 계산한 뒤 연간 최대값을 사용한다. 23시·24시·다음날 1시처럼 날짜를 넘는 구간은 제외한다.
- 집중호우 빈도: 위 3시간 합이 **60mm를 초과**한 날짜 수. 하루에 여러 구간이 초과해도 1일이다. 60mm와 같은 값은 세지 않는다.

## 원본과 연결

주차장 806개와 저지대 자료를 관리번호로 연결한다. 강수 집계값은 2025년 5개 서비스 구의 주차장 163개에 대응한다. 다른 구의 강수 참고 지표는 미산정이다.

침수 원본은 1,132개 대표좌표와 침수심을 포함한다. 경계 도형은 포함하지 않는다. 대표좌표까지의 최소 직선거리는 실제 침수구역 경계까지의 최소거리와 다르므로 사용자가 그 대안을 선택한 경우에만 사용한다. 이 경우 가까운 대표좌표의 침수심을 연결하고, 모든 등록 주차장의 최소거리 중 최대값을 정규화 기준으로 사용한다. 화면 검색·반경에 따라 기준을 다시 계산하지 않는다.

## 적용 기준

`data/risk_config.json`에서 대표좌표 직선거리, 가까울수록 높은 거리 위험점수, 제공된 강수자료 최대값으로 나누는 정규화를 적용한다. 침수심 기준 최대값은 0.5, 강수 기준 최대값은 91, 저지대 기준은 100이다. 거리 기준은 806개 주차장의 최근접 대표좌표 거리 중 최대값으로 고정하며 검색 범위별로 바꾸지 않는다. 경계 도형이 없는 상태의 대표좌표 기반 추정치로 표시한다.

강수 자료를 갱신하면 강수 참고 지표가 바뀐다. 새 지역의 최종 점수는 점수 CSV에 관리번호와 정수 점수를 추가한다.

강수 파일은 연간 집계값이다. 시간별 관측 원본이 없으므로 집계 과정 자체는 재검증하지 못했으며, 집계 항목으로 계산한 강수위험도가 파일의 값과 일치하는지는 확인한다. `services.risk_model.annual_rainfall_metrics`에 시간별 원본을 연결하면 위 규칙으로 집계할 수 있다. 날짜별 1~24시 자료를 사용하며, 결측 시각과 중복 시각은 오류로 표시한다.

## 검증

프로젝트 루트에서 `python -m unittest discover -s tests -t .`를 실행한다. CSV 점수 137개의 관리번호별 일치, 서비스 지역의 미산정 26개, 정수 데이터, 최근접 침수 대표좌표와 원본 해시를 검사한다. `tests/fixtures/risk_audit.json`은 참고 자료의 기존 독립 검증 기준을 담는다.
