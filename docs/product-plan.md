# 화면 기획 — 침착

원본은 팀 노션 「프론트엔드 기획」(2026-11-09 내보내기)입니다. 이 문서는 원본 글과 시안 이미지를 화면별로 정리한 것입니다. 시안 이미지에는 수정 사안이 반영되기 전 그림이 섞여 있으므로 **글이 이미지보다 우선**합니다. 기획에 없어 정해지지 않은 것은 「팀 확인 필요」로 적었습니다.

## 콘셉트

- 서비스 이름: 침착 — 데이터로 확인하는 내 주변의 침수 위험 주차장
- 상단 부제(최신 시안): 「데이터 기반 침수 위험 주차장 비교 서비스」
- 사용 흐름: 현재 위치 확인 → 정한 반경(500m, 1km, 1.5km, 2km) 안의 주차장을 거리순으로 검색 → 고른 주차장의 상세 정보 확인
- 디자인 방향: 복잡한 분석 결과를 일반 사용자도 쉽게 이해할 수 있는 깔끔한 대시보드
- 색: 흰색과 파란색을 기본으로 하고, 위험도는 붉은 계열의 진하기로 구분(아래 「색」)

## 전체 화면 공통

- 「2025년 데이터 기반 상대적 위험도이며 실시간 침수 예측이 아님」 안내를 지도와 위험지수 옆에 항상 표시합니다. 최신 시안은 지도 위에 붉은 띠로 「2025년 데이터 기반 상대적 위험도 · 실시간 침수 예측 아님」을 둡니다.
- 회원가입·로그인 기능과 회원 전용 기능은 없습니다. 시안의 「로그인」 버튼, 알림 종 아이콘, 즐겨찾기 별은 만들지 않습니다.
- 주차장 유형(지상/지하) 자료는 쓰지 않습니다.

## 메뉴

최신 시안(`plan-images/search-nearby-tab.jpg`)은 상단 가로 메뉴 3개입니다.

1. 주차장 탐색 — 첫 화면(홈)
   - 탭 A: 주변 주차장 검색
   - 탭 B: 주차장 상세 비교
   - 화면 아래: 데이터 출처 / 계산 방법 탭
2. 데이터 분석 결과 — 페이지 이름은 「데이터 분석 결과 대시보드」
3. FAQ

처음 사이트맵(`plan-images/sitemap.png`)의 「홈」과 「분석 기준」 메뉴는 없어졌습니다. 홈은 주차장 탐색이 맡고, 분석 기준은 주차장 탐색 아래 탭으로 들어갑니다.

팀 확인 필요: 원본 글은 「플랫폼 왼쪽 사이드바 정렬 순서는 홈(주차장 탐색),」에서 끊겨 있고, 최신 시안은 상단 가로 메뉴입니다. 메뉴 위치(상단/왼쪽)를 정해야 합니다. 순서는 최신 시안대로 주차장 탐색 → 데이터 분석 결과 → FAQ 로 둡니다.

## ① 주차장 탐색 — 탭 A 주변 주차장 검색

시안: `search-nearby-tab.jpg`(최신), `search-draft-a.jpg`·`search-draft-b.jpg`(예전, 오른쪽 상세 패널 참고용)

첫 화면 머리:

- 제목 두 줄 「데이터로 확인하는 / 내 주변의 **침수 위험** 주차장」(「침수 위험」만 파란색)
- 설명 「2025년 강수량, 지형(고도), 과거 침수 이력을 분석해 주차장별 상대적인 침수 위험도를 확인할 수 있습니다.」

처음 열었을 때:

- 왼쪽에 거리순 주차장 목록, 오른쪽에 큰 지도가 나옵니다. 첫 화면 목록은 거리순으로만 정렬합니다.
- 「현재 위치 기반 주차장 검색」과 내 위치 표시(시안 예: 「내 위치: 서울 강서구 마곡동」)
- 검색 반경 선택: 500m / 1km / 1.5km / 2km 버튼 묶음(시안 기본값 2km)
- 목록 머리 「주변 주차장 목록 (반경 2km) · 총 N개」
- 목록 한 줄: 순번, 주차장 이름, 주소, 위험지수(점수와 등급 색 배지). 지상/지하 표시는 없습니다. 시안은 한 쪽에 5개씩 보여 주고 쪽 번호를 둡니다.
- 지도: 내 위치(파란 점), 반경 원과 「반경 2km」 표시, 주차장 마커(목록 순번, 등급 색), 확대·축소·내 위치 버튼
- 지도 범례 「위험지수 등급 (상대적 위험도)」: 상대적 낮음(0~39점) / 보통(40~69점) / 상대적 높음(70~100점)

주차장을 골랐을 때:

- 지도가 작아지고, 오른쪽에 고른 주차장의 상세 위험지수가 나옵니다.
- 상세 구성: 주차장 이름과 주소, 위험지수(점 / 100)와 등급, 요인별 값 세 가지(1 강수량 위험, 2 지형(고도) 위험, 3 침수 이력 위험), 안내 문구
- 예전 시안의 오른쪽 「선택한 주차장」 패널이 모양 참고가 됩니다(요인별 막대와 비율, 아래 안내 상자).

팀 확인 필요: 사용자 위치를 받는 방법(브라우저 위치 권한, 주소 입력, 기본 위치 등)은 기획에 없습니다.

## ① 주차장 탐색 — 탭 B 주차장 상세 비교

시안: `search-compare-tab.jpg`, `compare-example.png`

- 검색 결과에서 고른 주차장 2~3개를 한 화면에 나란히 비교합니다(최대 3개).
- 정렬 기준을 위험도 낮은 순 / 위험도 높은 순 / 거리순으로 바꿀 수 있습니다.
- 보여 줄 것(유지 사안)
  - 침수 위험지수(점 / 100)와 상대적 위험 등급
  - 강수량, 지형(고도), 과거 침수 이력별 분석값(시안은 가중치와 함께 막대로 표시)
  - 주소, 사용자 위치에서의 거리
  - 분석 결과 해석(시안 예: 「마곡나루 공영주차장이 세 가지 위험 요인 모두에서 상대적으로 낮은 값을 보이며, 비교한 주차장 중 침수 위험이 가장 낮은 것으로 분석되었습니다.」)
  - 유의사항(문구는 `risk-index.md` 「안내 문구」)
- 지운 것: 주차장 유형(지상/지하), 침수 대표지점까지의 거리, 침수구역 중첩 여부
- 시안의 초록·노랑·빨강 색과 「낮은 위험」 방패 아이콘은 쓰지 않고, 모두 붉은 계열 진하기로 표시합니다.
- 시안의 주차장 사진과 「비교 분석하기」 버튼, 미니 지도는 기획 글에 언급이 없습니다(선택 사항).
- 시안 상단 문구: 「위험지수는 상대적 위험 수준(0~100)을 의미하며, 실제 침수 발생을 보장하지 않습니다.」

## ① 주차장 탐색 — 화면 아래 데이터 출처·계산 방법

- 따로 있던 「데이터 / 분석 기준」 페이지는 없앴습니다. 주차장 탐색 화면을 아래로 내리면 데이터 출처와 계산식(계산 방법)만 간결하게 탭 두 개로 보여 줍니다.
- 내용은 `risk-index.md` 의 「사용 자료」와 「계산식」을 씁니다. 예전 페이지 시안 `data-criteria-draft.jpg` 는 내용 참고용입니다.

## ② 데이터 분석 결과 대시보드

시안: `dashboard-draft.jpg`(예전 「분석 결과 예시」)

- 개별 주차장보다 분석 대상 전체의 통계와 경향을 보여 주는 페이지입니다. 시안보다 간결하게 다시 구성합니다.
- 페이지 이름: 「데이터 분석 결과 대시보드」
- 보여 줄 것
  - 분석 대상 주차장 총개수
  - 위험 등급별 주차장 수(와 비율)
  - 위험지수 분포 파이차트(시안은 가운데가 빈 도넛)
  - 위험지수 분포(구간별) 막대 그래프(시안 구간: 0~20, 21~40, 41~60, 61~80, 81~100)
  - 위험지수 상위 주차장(상위 5개)과 하위 주차장(하위 5개): 순위, 주차장명, 위험지수
- 지운 것: 분석 지역(서울시 25개 자치구 카드), 서울시 자치구별 위험도 지도, 주차장 유형별 평균 위험지수, 화면 아래 주요 분석 인사이트 전부
- 시안의 등급 경계(0~33 / 34~66 / 67~100)와 초록·노랑·빨강은 예전 것입니다. 최신 등급 경계와 붉은 계열을 씁니다.
- 대시보드에도 「상대적 위험도 · 실시간 예측 아님」 안내를 둡니다.

## ③ FAQ

시안: `faq-draft.jpg`, `faq-database-example.png`

- 질문 카테고리를 왼쪽에서 질문 목록 위쪽(상단)으로 옮깁니다.
- 기본 카테고리는 「전체」이고, 핵심 질문과 답변 5개만 위에 먼저 보여 줍니다.
- 시안의 카테고리(질문 수): 서비스 이용(4), 침수 위험도 지수(5), 데이터 및 분석 기준(3), 안전 및 유의사항(3), 계정 및 위치정보(3) — 모두 18개. 로그인이 없어졌으므로 계정 관련 질문은 빼고 「위치정보」만 남깁니다.
- 시안에 보이는 질문
  - 서비스 이용: 이 서비스는 어떤 서비스인가요? / 내 주변 주차장은 어떻게 찾을 수 있나요? / 위험도가 낮은 주차장은 어떻게 찾나요? / 검색 결과에 원하는 주차장이 표시되지 않는 이유는 무엇인가요?
  - 침수 위험도 지수: 위험도 지수가 낮으면 안전한 주차장인가요?
  - 데이터 및 분석 기준: 강수량은 어느 시점의 데이터를 기준으로 하나요?
  - 안전 및 유의사항: 현재 비가 많이 오는데 주차해도 되나요?
  - 위치정보: 제 위치정보는 저장되나요?
- 시안에 보이는 답(「이 서비스는 어떤 서비스인가요?」): 「강수량, 지형적 특성, 과거 침수 이력 데이터를 분석하여 주차장별 상대적인 침수 위험도를 비교할 수 있도록 돕는 서비스입니다. 현재 위치 주변의 주차장을 검색하고 위험도 지수와 주요 위험 요인을 확인할 수 있습니다.」
- 시안의 FAQ 는 노션 데이터베이스(질문, 카테고리)로 관리하는 예시입니다. 앱에서는 `core/faq.py` 에 둡니다.
- 팀 확인 필요: 나머지 질문과 답, 어느 5개를 핵심 질문으로 할지(`faq-database-example.png` 에 카테고리마다 하나씩 보이는 5개가 후보), 시안 아래 「이메일 문의」 칸을 둘지와 실제 연락처(시안의 주소는 예시라 쓰지 않음)

## 색

- 기본: 흰 배경, 파란색 강조 `#1E6FD9`(`.streamlit/config.toml`)
- 위험 등급 색(제안 — 최신 시안의 연분홍·분홍·진홍을 따름, 팀 확정 전)

| 등급 | 점수 | 색 |
|---|---|---|
| 상대적 낮음 | 0~39 | 연한 빨강 `#F6B8B8` |
| 보통 | 40~69 | 중간 빨강 `#E06666` |
| 상대적 높음 | 70~100 | 진한 빨강 `#A51C1C` |

- 같은 색을 목록 배지, 지도 마커, 범례, 차트, 표에 똑같이 씁니다.

## 문구 규칙

- 위험지수는 항상 「상대적」 위험도라고 밝힙니다.
- 「안전」「안전한 주차장」처럼 위험이 없다고 읽히는 말을 쓰지 않습니다. FAQ 질문처럼 사용자의 물음을 옮길 때만 예외입니다.
- 등급 이름은 「상대적 낮음 / 보통 / 상대적 높음」을 씁니다.
- 실시간 정보처럼 보이는 말(「현재 침수 위험」「지금 위험」)을 쓰지 않습니다.
